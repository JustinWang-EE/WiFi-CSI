## MM-Fi toolbox

The cache-building script interoperates with a separately downloaded copy of
the official MM-Fi toolbox. No MM-Fi toolbox source is vendored here. At the
time of this release audit, the upstream repository did not contain an
explicit top-level software license file. Confirm permission with the upstream
authors before redistributing or adapting their toolbox code.
